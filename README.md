# homebrew-tap

Homebrew tap for [LucasSantana-Dev](https://github.com/LucasSantana-Dev) tools.

## Install

```bash
brew install LucasSantana-Dev/tap/sharekit
```

Or tap first then install:

```bash
brew tap LucasSantana-Dev/tap
brew install sharekit
```

## Tools

| Formula | Description |
|---|---|
| `sharekit` | Share your AI coding setup — install profiles from GitHub with one command |

## Update

Formulas are updated automatically when a new release is tagged in the source repo.
